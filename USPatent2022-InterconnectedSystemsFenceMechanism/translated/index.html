    ABSTRACT

    An apparatus to facilitate memory barriers is disclosed. The apparatus comprises an interconnect, a device memory, a plurality of processing resources, coupled to the device memory, to execute a plurality of execution threads as memory data producers and memory data consumers to a device memory and a system memory and fence hardware to generate fence operations to enforce data ordering on memory operations issued to the device memory and a system memory coupled via the interconnect.

    公开了一种用于促进内存屏障的装置。该装置包括互连结构、设备存储器、多个处理资源以及栅栏硬件，所述多个处理资源耦合到所述设备存储器，用于执行多个执行线程作为针对所述设备存储器和系统存储器的存储器数据生产者与消费者，所述栅栏硬件用于生成栅栏操作，以对发往经由所述互连结构耦合的所述设备存储器和系统存储器的存储器操作强制执行数据排序。

    BACKGROUND

    5

    5

    Graphics processing units (GPUs) are highly threaded machines in which hundreds of threads of a program are executed in parallel to achieve high throughput. Tile based rendering architecture in GPUs provides significant memory bandwidth savings in certain three-dimensional (3D) gaming workloads. GPUs typically perform synchronization between graphics drivers and the underlying GPU hardware components using memory barriers (or fence operations). A fence operation causes the GPU to enforce an ordering constraint on memory operations issued before and after the operation.

    图形处理单元（GPU）是高度线程化的设备，其中程序的数百个线程并行执行以实现高吞吐量。GPU中基于图块渲染的架构在某些三维（3D）游戏工作负载中可显著节省内存带宽。GPU通常使用内存屏障（或栅栏操作）在图形驱动程序与底层GPU硬件组件之间进行同步。栅栏操作会使GPU对该操作前后发出的内存操作强制执行一种排序约束。

    本文档是一项专利(US 11,321,262 B2)，描述了一种用于互连计算系统中栅栏机制的装置和方法。其主题是在包含多个 CPU 和 GPU 的复杂多插槽架构中强制执行内存操作排序，每个 CPU 和 GPU 各自拥有系统内存和设备内存，并通过 CPU 和 GPU 互连进行连接。

    其关键贡献在于 GPU 内部的一个专用“栅栏硬件”组件，该组件生成栅栏操作，以确保跨系统内存和设备内存的数据排序。该专利指出的问题是，多插槽系统中的数据路径和信号路径可能不同，从而可能违反排序。所提出的方法定义并实现了四种特定的栅栏类型：1) 到系统内存的释放栅栏(Release Fence to System Memory)，通过生成对系统内存位置的读请求并等待数据返回，保证所有先前的写操作被推送到 CPU 互连域；2) 到设备内存的释放栅栏(Release Fence to Device Memory)，确保写操作被推送到 GPU 互连；3) 从系统内存的获取栅栏(Acquire Fence from System Memory)；4) 从设备内存的获取栅栏(Acquire Fence from Device Memory)，这涉及 GPU 之间的通信，以确保所有远程写操作全局可见。该机制可以根据所需的性能粒度，从图形管线的各个阶段(例如帧边界、计算遍历器完成或内核)发出这些栅栏操作。

    本文是一份描述互连计算系统中栅栏机制的装置和方法的专利（US 11,321,262 B2）。其主题是在包含多个CPU和GPU、每个拥有各自系统内存与设备内存并通过CPU与GPU互连进行连接的复杂多插槽架构中，强制执行内存操作顺序。核心贡献是GPU内部的一个专用“栅栏硬件”组件，该组件生成栅栏操作以确保跨系统内存和设备内存的数据排序。该专利指出，在多插槽系统中数据和信号路径可能不同，从而潜在地破坏顺序。所提出的方法定义并实现了四种特定栅栏类型：1）系统内存释放栅栏，通过生成对系统内存位置的读取请求并等待数据返回来确保所有之前的写操作被推送到CPU互连域；2）设备内存释放栅栏，确保写操作被推送到GPU互连；3）系统内存获取栅栏；以及4）设备内存获取栅栏，其涉及GPU之间的通信以确保所有远程写操作全局可见。该机制可根据所需的性能粒度从图形管线的各个阶段（例如，帧边界、计算遍历器完成或内核）发出这些栅栏。
